Ngôn ngữ dùng trong các buổi họp Scrum và code review hàng ngày.

62.1 Thuật ngữ Agile/Scrum

Thuật ngữNghĩa

backlogdanh sách công việc cần làm

62.2 Mẫu câu cho Daily Stand-up

Yesterday, I finished implementing the login API. Today, I'll work on writing unit tests for it. I don't have any blockers at the moment.
→ Cấu trúc chuẩn của một câu trả lời trong daily stand-up: Hôm qua đã làm gì → Hôm nay sẽ làm gì → Có gặp trở ngại (blocker) gì không.

62.3 Mẫu câu Code Review

Tình huốngMẫu câu
Đề xuất thay đổiCould you consider using a more descriptive variable name here?
Khen ngợiNice solution! This is much cleaner than the previous approach.
Nêu vấn đề tiềm ẩnThis might cause a null pointer exception if the input is empty.
Yêu cầu giải thíchCan you explain the reasoning behind this implementation?

62.4 Bài tập thực hành

1. Viết câu trả lời daily stand-up cho việc đã hoàn thành phần debug traffic light, hôm nay sẽ viết báo cáo.
✅ Ví dụ: "Yesterday, I finished debugging the traffic light control logic. Today, I'll be writing the technical report. No blockers so far."
2. Viết một comment code review lịch sự đề xuất đổi tên biến "x" thành tên rõ nghĩa hơn.
✅ Ví dụ: "Could you consider renaming 'x' to something more descriptive, like 'countdownSeconds'?"

62.5 Quiz trắc nghiệm — Chương 62

🎯 Tổng kết Chương 62

  • Nắm vững thuật ngữ Agile/Scrum: sprint, backlog, stand-up, retrospective.
  • Cấu trúc trả lời stand-up: hôm qua → hôm nay → blocker.
  • Code review: dùng ngôn ngữ lịch sự, mang tính xây dựng, không chỉ trích cá nhân.

Viết Tài Liệu Kỹ Thuật & Báo Cáo Lỗi

Kỹ năng viết bug report và tài liệu kỹ thuật rõ ràng, chuyên nghiệp.

63.1 Cấu trúc Bug Report chuẩn

PhầnNội dung
TitleTóm tắt ngắn gọn lỗi gặp phải
Steps to ReproduceCác bước cụ thể để tái hiện lỗi
Expected BehaviorHành vi mong đợi đúng
Actual BehaviorHành vi thực tế xảy ra (lỗi)
EnvironmentThông tin môi trường (OS, browser, version)
Screenshots/LogsẢnh chụp màn hình hoặc log lỗi đính kèm
Ví dụ — Bug Report mẫu
Title: Countdown timer displays incorrect value after page refresh

Steps to Reproduce:
1. Open the traffic light simulator
2. Let the countdown run for 5 seconds
3. Refresh the page

Expected Behavior: The countdown should reset to the initial value (30 seconds).

Actual Behavior: The countdown displays "NaN" instead of resetting.

Environment: Chrome 126, Windows 11
📌 Important
Bug report càng cụ thể, khách quan, có thể tái hiện lại được càng giúp đội ngũ kỹ thuật xử lý nhanh hơn. Tránh viết mơ hồ như "It doesn't work" — luôn mô tả chính xác điều gì xảy ra và trong hoàn cảnh nào.

63.2 Bài tập thực hành

1. Viết tiêu đề (Title) cho lỗi: nút "Submit" không phản hồi khi click trên Safari.
✅ Ví dụ: "Submit button does not respond when clicked on Safari"
2. Viết phần "Expected Behavior" và "Actual Behavior" cho lỗi form validation không hiển thị thông báo lỗi.
✅ Ví dụ: "Expected Behavior: An error message should appear when the email field is left empty. Actual Behavior: The form submits without any validation error message."

63.3 Quiz trắc nghiệm — Chương 63

🎯 Tổng kết Chương 63

  • Bug report chuẩn gồm: Title, Steps to Reproduce, Expected/Actual Behavior, Environment.
  • Viết cụ thể, khách quan, có thể tái hiện được — tránh mô tả mơ hồ.
